# Diagvo vehicle data

Open vehicle data used by the Diagvo diagnostic app.

| Folder | Content | Licence |
|---|---|---|
| [`obdb/`](obdb/) | Vehicle model generations and years adapted from [OBDb](https://github.com/OBDb) | CC BY-SA 4.0 |
| [`obdb/signals/`](obdb/signals/) | Manufacturer parameter definitions (services 21/22) adapted from OBDb; not verified by Diagvo | CC BY-SA 4.0 |

Catalog entries describe which vehicles exist; they do not state that a vehicle
is supported for diagnosis.
